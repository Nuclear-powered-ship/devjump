手动方案 跳转全部失败时用

方法一：连点版本号（最可靠）
设置 → 关于平板 / 我的设备 → 找到「版本号」→ 连续快速点 7 次 → 提示"已进入开发者模式"。
部分学习机需要先在家长端解除「禁止修改系统设置」。
方法二：电脑 ADB（需已开 USB 调试）
手机/平板连电脑，执行下面的命令。 
adb shell settings put global development_settings_enabled 1
adb shell am start -a android.settings.APPLICATION_DEVELOPMENT_SETTINGS
adb shell settings put secure install_non_market_apps 1
方法三：展讯芯片机型
拨号盘输入 *#*#83781#*#* 或打开「工程模式」→ DEBUG&LOG → 打开 USB Debug。
本页只发送系统 Intent，不修改任何文件、不刷机。
设备差异较大，部分入口可能不存在，属正常现象。
